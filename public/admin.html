My Account

Change the email or password you use to log in here. Your current password is required to confirm either change — this also signs you out on any other device automatically if you change your password.

WhatsApp

The site's chat widget sends visitor messages to this number. Without any extra setup, it opens WhatsApp with the message pre-filled for the visitor to send. If you also fill in the advanced fields below with a real Meta WhatsApp Business Cloud API token, messages get delivered to you automatically instead.

Advanced (optional — Meta Cloud API)

Webhook URL to give Meta: /api/whatsapp/webhook

Google Sign-In

Lets visitors sign in with their Google account instead of creating a password. Needs a free OAuth Client ID from Google Cloud Console — create an "OAuth client ID" of type "Web application", and add this site's URL under "Authorized JavaScript origins". The circular Google button on the site stays hidden until this is filled in.
